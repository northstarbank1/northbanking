# Northstar Bank — fictional dashboard demo

A responsive front-end prototype built with Vite and plain JavaScript. It uses illustrative account values and sample activity only. It does not connect to a financial institution, authenticate users, process payments, or deposit checks. Use fictional details only.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## Build

Run `npm run build`. Vite writes the deployable site to `dist/`. To preview that build locally, run `npm run preview`.

## Publish through GitHub and Netlify

1. Upload the contents of this project folder to a GitHub repository (not the ZIP file itself).
2. In Netlify, choose **Add new site → Import an existing project** and connect that repository.
3. Netlify should detect the included `netlify.toml`. Confirm the build command is `npm run build` and the publish directory is `dist`.
4. Deploy the site. After each change, commit and push to GitHub; Netlify will rebuild on the next deploy.

## Notes

- Keep the fictional-demo disclosure visible so visitors do not mistake the prototype for a real bank.
- Never ask visitors to enter real banking passwords or financial account details.
- This is a reconstructed demo package, not an exact export of another hosted project.
